📒 VirtualBox 虚拟机入门学习笔记

整理自 2026.8.17 对话，涵盖：基础概念 → 磁盘管理 → 网络配置 → 常用操作

一、基本概念

术语含义宿主机（Host）你真实的物理电脑客户机（Guest）虚拟机里跑的系统虚拟磁盘（.vdi）宿主机上的一个文件，对客户机来说就是"硬盘"快照（Snapshot）存档点，可一键回档到拍摄时刻

能建多少个虚拟机？

建多少个：理论上无上限，列表里随便排

同时跑几个：取决于内存大小（CPU/内存是共享的，硬盘不是瓶颈）

举例：16GB 内存笔记本 → 建 5 个没问题，同时开 2 个（各 4GB）流畅

二、虚拟磁盘

两种分配方式

类型宿主机实际占用特点动态分配（默认✅）用多少占多少，最大到设定值省空间，推荐新手固定大小创建时一口气占满性能略好，不碎片，但费空间

关键规则

分配 40GB = 虚拟机最多用 40GB

动态盘只增不减：虚拟机里删文件，宿主机 .vdi 文件不会自动缩小

有快照会额外占宿主机空间

查看磁盘类型

虚拟机关机 → 设置 → 存储 → 点 .vdi 文件 → 右侧看是 Dynamically allocated 还是 Fixed size

压缩（Compact）步骤

⚠️ 操作前先拍快照或备份 .vdi

虚拟机里（管理员 CMD）：

下载 SDelete → sdelete64.exe -z C:（把空闲空间填零）

宿主机里（CMD 进 VirtualBox 目录）：

VBoxManage modifymedium disk "路径\xxx.vdi" --compact

有快照先合并快照再压缩

扩容（Resize）步骤

宿主机：

VBoxManage modifymedium disk "路径\xxx.vdi" --resize 81920

（81920 MB = 80GB，按需换算）

虚拟机里：diskmgmt.msc → 右键 C 盘 → 扩展卷

⚠️ 有快照先删快照；扩展卷灰色说明中间夹了恢复分区

三、增强功能（Guest Additions）

装了之后获得：

✅ 分辨率自适应窗口大小

✅ 鼠标无缝进出（不用按右Ctrl）

✅ 共享剪贴板（宿主机复制→虚拟机粘贴）

✅ 共享文件夹

安装方法：设备 → 安装增强功能 → 虚拟机里运行安装程序 → 重启

四、网络模式（重点⭐）

六种模式一览

模式上网宿主机↔︎虚拟机局域网其他设备访问典型用途NAT（默认）✅❌（需端口转发）❌上网、学习、装软件NAT Network✅✅（同网络内）❌（需端口转发）多台虚拟机互通+上网桥接✅✅✅当服务器、被手机/同事访问仅主机（Host-Only）❌✅❌封闭测试、宿主机私聊内部网络❌❌❌纯虚拟机集群、隔离实验未连接❌❌❌相当于拔网线

NAT vs 桥接（核心区别）

NAT桥接类比住酒店（前台转接）租公寓（独立门牌）虚拟机 IP10.0.2.x跟宿主机同段 192.168.x.x外面能找到虚拟机吗❌✅安全性🔒 高⚠️ 暴露

🏆 最推荐方案：双网卡

网卡 1 = NAT（上网）

网卡 2 = Host-Only（宿主机私聊）

安全 + 方便，不用端口转发

多网卡注意事项

多个网卡都有默认网关会冲突 → 只留一个网卡的默认网关

Host-Only 网卡需在 VirtualBox 网络管理器里确认存在

五、查看虚拟机 IP

正确操作（虚拟机 Windows 里）：

Win + R → 输 cmd → 回车（先打开窗口）

输入 ipconfig → 回车

看 IPv4 地址

看到的 IP说明10.0.2.xNAT 模式192.168.1.x 等同宿主机桥接模式192.168.56.xHost-Only 模式172.16~31.x.xNAT Network 模式

⚠️ 不要 Win+R 直接输 ipconfig，窗口会一闪而过。正确是先开 cmd 再输命令。

六、日常操作速查

操作方法找回消失的虚拟机双击文件夹里的 .vbox 文件，或管理器里"注册/导入"鼠标被锁在虚拟机里按右 Ctrl 释放全屏右 Ctrl + F（装增强功能后）拍快照机器 → 拍摄快照共享文件夹设备 → 共享文件夹端口转发（NAT 下访问虚拟机服务）设置 → 网络 → 网卡 → 端口转发

七、新手建议路线

✅ 装好系统 → 装增强功能 → 拍第一个快照（干净系统） ✅ 日常用、装软件、随便折腾 ✅ 崩了 → 回快照 → 再来 ✅ 玩熟了 → 建第二个虚拟机试不同系统 ✅ 需要被访问 → 加第二块网卡（Host-Only）
